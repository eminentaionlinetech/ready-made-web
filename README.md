# Ready Made Web Market

Build a marketplace where I sell pre-built websites. Pages: home with a grid of website cards (screenshot, title, price, category filter), a detail page with a live demo link, description, and Buy button, and a buyer dashboard. Modern, clean design.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://ready-made-web-market.lovable.app
